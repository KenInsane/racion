# Белковая неделя на двоих

Рацион на неделю на двоих (100+ г белка каждому, клетчатка, ПП-сладкое): свои рецепты и идеи из рилсов, общее редактируемое меню, списки закупок, которые считаются из меню, галочки и учёт трат. Сайт статический (GitHub Pages), общие данные лежат в Firebase Firestore.

## Как пользоваться

- Откройте сайт на телефоне и добавьте его на главный экран: Safari → «Поделиться» → «На экран Домой», Chrome → меню → «Добавить на главный экран».
- **Траты → Общий доступ → Создать общий список** и отправьте ссылку второму человеку. У кого есть эта ссылка, тот видит те же галочки и траты. Ссылку не публикуйте.
- «Неделя»: любое блюдо можно заменить, убрать или добавить. В «Идеях» у каждого рецепта есть «+», чтобы поставить его в нужный день.
- В магазине: «Закупки» → отмечаете купленное → «Записать сумму чека».
- Без сети всё работает: изменения сохраняются на телефоне и отправляются сами, когда появится связь.

## Настройка Firebase (один раз)

1. https://console.firebase.google.com → **Add project** (Google Analytics не нужен).
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable.**
3. **Build → Firestore Database → Create database**, регион `eur3 (europe-west)`, режим production.
4. **Firestore → Rules:** вставить содержимое `firestore.rules` → **Publish**.
5. **Project settings → General → Your apps → Web (`</>`)**, зарегистрировать приложение, скопировать объект `firebaseConfig` в `firebase-config.js`.
6. **Authentication → Settings → Authorized domains:** добавить `keninsane.github.io`.

## Обновить меню

Продукты, рецепты и меню по умолчанию лежат в `data.js`. Он собирается скриптом `build_v2.py` в папке проекта из `v2/mine.json` (свои рецепты), `v2/catalog_result.json` (каталог продуктов) и `plan.json` (идеи). Само меню недели и галочки хранятся в Firestore, траты от меню не зависят.
